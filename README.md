# ELT 295 Labs

Arduino Uno labs where each student's board reports to a live dashboard on the instructor's computer.

| Folder | Who | What's in it |
|---|---|---|
| [`student/`](student/README.md) | Students | Arduino sketches, wiring, the `bridge.html` that connects a board to the class, troubleshooting |
| [`teacher/`](teacher/README.md) | Instructor | The dashboard server, one-click launcher, and the brief for writing the labs |

```
Uno (USB) -> student's browser (bridge.html) -> classroom network -> instructor's server -> dashboard
```
